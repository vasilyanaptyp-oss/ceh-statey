# Цех статей

Сервис SEO-статей под ключ: агентный конвейер, 16 этапов, 7 независимых проверок, анти-ИИ правка, юр-модуль РФ.

**Сайт:** https://vasylian.com/ceh-statey/

## Структура

- `index.html` — лендинг (одностраничник)
- `offer.html` — публичная оферта
- `privacy.html` — политика конфиденциальности (152-ФЗ)
- `styles.css` — дизайн-система (шрифты самохостятся в `fonts/`)
- `main.js` — минимальная интерактивность
- `og-image.png` — карточка для соцсетей (генератор — `og.html`, не деплоится)

## Качество

Lighthouse 100/100/100/100, LCP ~200 мс, без внешних зависимостей (работает при блокировках Google в РФ).

Прошёл воркфлоу-ревью 47 агентами: дизайн, доступность, копирайт, код, редтим (безопасность и честность клеймов), SEO — 29 подтверждённых находок закрыто.

## Лицензии шрифтов

Unbounded, Golos Text, JetBrains Mono — распространяются по SIL OFL, файлы в `fonts/`.
